First Pack Pro v25 — Minecraft Java resource directory

Major updates:
- Fixed the built-in First Pack assistant and expanded its answers.
- Added dedicated Bedwars section with PVPRP-linked packs and local banners.
- Added a unique local banner for every map and repaired missing asset paths.
- Added favorites hearts, download history and account dashboard.
- Added local username uniqueness protection with the requested message.
- Added FirstSmile verified blue check for comments.
- Added comment moderation/security bot that filters inappropriate words before display.
- Added Minecraft server directory: TrexMine, GameUP, Hypixel and Mineplex.
- Added Rubika link: https://rubika.ir/FirstPACK
- Improved typography, responsive UI and image loading/performance.
- Resource ratings now show rating counts and remain stored locally.

Important architecture note:
This package is still a static site. Accounts, favorites, ratings and comments are stored in the visitor's browser. True shared accounts, shared ratings, and shared comments across devices require a backend/database (for example Supabase/Firebase or a custom API). The UI is prepared for that next step.
